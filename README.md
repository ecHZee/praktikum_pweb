# Praktikum PWeb — Diary

Project praktikum Pemrograman Web yang berisi aplikasi diary dengan bagian frontend dan backend.

## Struktur

- `diary/` — aplikasi frontend
- `diary-backend/` — backend pendukung

## Menjalankan

Masuk ke masing-masing folder dan ikuti package/configuration yang tersedia di dalamnya. Dependency frontend dan backend dikelola terpisah.

## Status

Project pembelajaran/praktikum. Repo ini dipertahankan sebagai arsip historis sampai dibandingkan dengan `pweb_labti`.
